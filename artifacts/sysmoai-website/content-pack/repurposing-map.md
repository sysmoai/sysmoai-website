# Repurposing Map — 4-Week Content Waterfall

*Each week's core idea cascades across all platforms. The same ANGLE is re-authored per platform — never just resized. Each platform demands different execution, not different ideas.*

---

## How to Use This Map

1. Start with the **LinkedIn tentpole** (carousel) — this is the richest version of the week's core idea
2. Extract the sharpest angle for the **X/Twitter thread** (each tweet must stand alone)
3. Distill to the single most visual hook for **Instagram feed**
4. Strip to one-liner or poll format for **Instagram Stories**
5. Find the short-form narrative arc for **TikTok/Reels**
6. Add personal context + founder POV for **Newsletter**

**Key rule:** Same angle, completely different execution. A feed caption is NOT a newsletter section with hashtags added. A Story is NOT a LinkedIn post cropped to 9:16. Re-author every time.

## Week 1 Core Idea: "The Chaos Is Not the Business — It's the Missing System"

**Central insight:** 847 unread messages. Orders missed while you sleep. A founder who can't take a day off — this is not a discipline problem. It's a systems problem. The pain is real, specific, and fixable.

**Funnel stage:** TOF — Recognition. Reader should feel seen before they feel sold to.

| Platform | File Ref | Hook Pattern | Execution |
|---|---|---|---|
| LinkedIn (Tentpole) | `linkedin.md` — L5 | Slippery Slope | 6-slide carousel showing how a missed DM compounds into a month of leaked revenue. Starts with one 2am message and follows each stage of the breakdown. Founder POV throughout. |
| X Thread | `x.md` — Thread W1 | Specificity Signal | 6-tweet thread: 847 unread → cost of missed DMs → the failed "hire someone" solution → the actual fix → a verified client result → CTA. Each tweet stands alone, quotable. |
| Instagram Feed | `instagram-feed.md` — IF3 | Curiosity Gap | 5-slide carousel caption. Hook: "How revenue disappears from F-commerce businesses every month (without anyone noticing)." Visual mockups of each stage — the 2am DM, the missed order, the auto-reply fix. |
| Instagram Stories | `instagram-stories.md` — IS1 | Pain (Single Frame) | ONE frame. "847 unread." in huge type. Nothing else. Red tint. Gut-punch visual. No explanation needed. CTA strip at bottom. |
| TikTok / Reels | `tiktok-reels.md` — TR1 | Specificity Signal | 28-sec script. Hook: "847 unread messages before 9am." Shows the missed order pattern → the 24/7 auto-reply fix → CTA. |

**The re-authoring principle in action:**
- LinkedIn carousel tells the story visually across 6 slides with context and resolution
- X thread compresses each stage to a quotable standalone tweet
- IG feed gives you the hook + scannable bullets + visual direction
- IG Story strips everything to a single word: "847 unread." — nothing else
- Reel brings it to life with B-roll and a 28-second narrative arc
- Newsletter adds the personal founder reflection and the deeper "why"

## Re-Authoring Checklist (Use Before Publishing Each Piece)

- [ ] Hook is written for the specific platform's truncation point (LinkedIn: 110 chars, IG: 125 chars, X: 280 chars total)
- [ ] Content is re-authored for platform format — NOT resized from another platform
- [ ] Exactly ONE CTA per piece (either `https://sysmoai.com/free-ai-audit` OR WhatsApp — never both)
- [ ] No banned openers ("I'm excited to share", "Hey everyone", etc.)
- [ ] Emoji usage within platform rules (0–2 LinkedIn, 2–4 IG, 0–1 X, 0 newsletter body)
- [ ] BDT formatted correctly (৳3,750 / ৳50,000 / ৳20,000)
- [ ] For Stories: all content confirmed within 14%–80% safe zone
- [ ] Hook pattern is not repeated back-to-back on the same platform in the same week
- [ ] All proof points traceable to Proof.tsx, Services.tsx, or blogPosts.ts — no invented stats
